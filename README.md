
# Standard Operating Procedure: Open WebUI Access

### Purpose
This SOP provides step-by-step instructions for securely connecting to the Mac Studio ("eliza") via to access the Open WebUI application. 

### Prerequisites
- GlobalProtect VPN access if connecting from outside the Pitt Network
- Request an account for open-webui through Linghai (l.wang@pitt.edu or slack)

## Step-by-Step SSH Setup Procedure

### 1. Connect to GlobalProtect VPN
Ensure you are connected to the Pitt Network via GlobalProtect VPN if you are accessing from outside the pittnet.
### 2. Access Open WebUI via Browser
Open your web browser and go to: 
<http://oac-eliza.oac.pitt.edu>

### 3. Login to Open WebUI
Use the credentials that were provided to you when your account after contacting Linghai (l.wang@pitt.edu or slack). If you forget your credentials, please reach out to Linghai for assistance.
